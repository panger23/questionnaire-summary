鲁小审 · 汇卷（扫描件智能汇总） Windows 免安装版
========================================

一、怎么用
----------
1. 把整个文件夹解压到任意位置（例如 D:\LuShen），不要只拷 exe。
2. 双击「start.bat」（或直接双击 LuShen.exe）。
3. 会弹出一个黑色命令行窗口，显示一行地址，例如：
       http://127.0.0.1:8765
   Chrome 会自动打开这个页面。没自动打开的话，把地址复制到 Chrome 地址栏。
4. 把扫描好的 PDF 拖进网页，选好「识别方式」，点上传即可。
5. 识别完在网页里看结果、改分，点「下载 Excel」保存到本地。

重要：用的时候不要关那个黑色窗口；关掉它服务就停了。

二、内网能用吗
--------------
能。默认「纯本地识别」完全离线，不需要联网、不需要装 Python 或 Java。
只有「LLM 复核」两种模式需要访问外部接口；内网没有外网时保持「纯本地识别」即可，
功能完整，只是少一道 AI 交叉校验。

三、要开 LLM 复核怎么办
----------------------
1. 网页右上角「设置」
2. 填 API 地址、模型名、API Key，点保存
3. 回到首页，识别方式里选「本地 + LLM复核可疑页」或「本地 + LLM全量复核」

Key 只保存在本机的 配置.json（和 exe 同目录），不会上传到任何地方。
配置.json 可以删掉，删掉后就是纯本地模式。

四、常见问题
------------
Q: 双击没反应 / 闪一下就没了？
A: 请用「启动.bat」启动，它会保留窗口显示报错信息。若提示缺少 DLL，
   通常是杀毒软件拦截了，把整个文件夹加入白名单即可。

Q: 提示端口被占用？
A: 程序会自动往后找空闲端口（8765、8766…），看窗口里实际显示的地址。

Q: 浏览器打开是空白？
A: 等 2~3 秒再刷新；或确认地址栏端口和窗口里显示的一致。

Q: 能不能多人共用一台机器？
A: 默认只监听本机（127.0.0.1），别人访问不到。每人解压一份自己用即可。
